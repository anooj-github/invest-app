Quick Setup Steps:
  1. Create a new spreadsheet at sheets.new.
  2. Go to Extensions > Apps Script, paste google-apps-script/Code.gs.
  3. Click Deploy > New deployment > Web app (Access: Anyone).
  4. Paste the generated URL above and click Save URL!
